The frontend for the **AI-Based Agricultural Advisory System for Multilingual Farmer Query Assistance**. Built with **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS v4**.

## 🌐 Live Application
- **Live Website**: [https://agri-advisory-frontend.onrender.com/](https://agri-advisory-frontend.onrender.com/)
- **Backend API**: [https://ai-based-agricultural-advisory-system-ouyx.onrender.com/](https://ai-based-agricultural-advisory-system-ouyx.onrender.com/)

## 🚀 Key Modules
- **Interactive Landing Page**: Live APMC commodity ticker, multilingual RAG query simulator, and agricultural zone explorer.
- **Farmer Dashboard**: 7-day weather forecasting via Open-Meteo, mandi price charts via Recharts, and soil management guide.
- **Multilingual Chat Terminal**: Conversational voice & text interface supporting English, हिन्दी (Hindi), and తెలుగు (Telugu).
- **Authentication**: Secure farmer sign-up and login with encrypted session persistence.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
